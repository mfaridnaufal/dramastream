Kebijakan privasi

Kebijakan untuk versi beta terbatas. Layanan dikelola oleh Pengelola DramaStream. Kontak untuk privasi dan bantuan: mfaridnaufal1993@gmail.com.

Data yang digunakan

Jika Anda membuat akun, email dan data autentikasi diproses melalui Supabase. Favorit, riwayat, dan posisi menonton dapat disimpan untuk akun Anda. Tanpa login, fitur tertentu menggunakan penyimpanan lokal browser.

Tujuan penggunaan

Data digunakan untuk masuk ke akun, menyimpan pilihan tontonan, melanjutkan episode, dan membatasi fungsi pengelolaan katalog kepada admin.

Penyimpanan di perangkat

Browser dapat menyimpan sesi login, preferensi, favorit, riwayat, dan progres. Menghapus data situs pada browser dapat menghapus data lokal serta mengeluarkan akun. Tindakan ini tidak otomatis menghapus data yang tersimpan di server.

Layanan pihak ketiga

Halaman dihosting melalui GitHub Pages. Supabase menyediakan autentikasi dan database. Pustaka pemutar dapat dimuat melalui CDN. Poster dan video dapat berasal dari server lain; ketika dimuat, penyedia menerima permintaan jaringan, termasuk alamat IP dan informasi teknis browser. Masing-masing penyedia memiliki kebijakan sendiri.

Permintaan terkait data

Anda dapat meminta informasi, perbaikan, atau penghapusan data akun melalui email pengelola yang tercantum di halaman kontak. Jangan mengirim kata sandi atau kode autentikasi. Penghapusan data browser berbeda dari penghapusan akun.

Lama penyimpanan dan penghapusan

Pada versi beta ini, data akun, favorit, riwayat, dan progres tidak dihapus otomatis berdasarkan usia data atau ketidakaktifan. Data tetap tersimpan sampai diubah melalui fitur yang tersedia atau sampai pengelola memproses permintaan penghapusan yang telah diverifikasi.

Penghapusan akun belum tersedia melalui tombol mandiri. Untuk mengajukan penghapusan, kirim email dengan subjek “Permintaan penghapusan akun DramaStream” dari email akun yang terdaftar. Sebutkan apakah permintaan berlaku untuk data tontonan saja atau seluruh akun. Jangan mengirim kata sandi atau kode verifikasi.

Pengelola memeriksa kepemilikan akun sebelum menghapus data server. Menghapus data situs di browser hanya menghapus salinan lokal dan tidak menghapus akun server. Catatan teknis atau cadangan yang dikelola penyedia tidak dijanjikan terhapus seketika; rincian retensinya perlu dikonfirmasi kepada penyedia saat permintaan diproses.

Perubahan kebijakan

Kebijakan diperbarui ketika praktik layanan berubah. Tanggal pembaruan ditampilkan di bagian atas halaman. Identitas layanan saat ini adalah Pengelola DramaStream. Jika identitas pengelola, kontak, atau praktik penyimpanan berubah, halaman ini akan diperbarui. Versi beta belum menerapkan retensi otomatis.
